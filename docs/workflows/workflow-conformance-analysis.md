# Workflow Conformance Analysis

本文档承接早期“流程遵循性分析”，关注当前实现是否真正遵守既定主链和跨层契约。

## 核心检查点

- 工作流阶段推进是否与共享类型和状态常量一致。
- 主进程的 IPC 行为、preload 暴露接口和 renderer 订阅是否同步更新。
- 证据链、报告和运行状态是否在 UI 中有对应展示，而不是停留在主进程内部。
- blocker、用户输入和用户批准路径是否能在主链中明确表达。

## 分析结论的使用方式

- 把该文档作为回归和重构时的人工检查清单，而不是单独的实现规范来源。
- 发现偏移时，优先修复代码与共享契约，再回写文档。

## 与测试的关系

- `pnpm run typecheck` 用于守住类型与契约一致性。
- `pnpm run build` 用于守住构建入口与资源路径。
- 关键 E2E 用于验证工作台入口、主链行为和 UI 保真。
