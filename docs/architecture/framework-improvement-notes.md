# Framework Improvement Notes

本文档收敛早期的框架改进建议，只保留对当前仓库仍有指导意义的改进方向。

## 当前改进重点

- 保持 `src/main`、`src/preload`、`src/renderer`、`src/shared` 四层单一主骨架。
- 收紧共享类型、IPC 和 UI 展示之间的契约，避免单层漂移。
- 持续减少历史命名、镜像结构和“临时兼容”分支。
- 把运行期目录、构建产物和仓库骨架彻底分开。

## 具体治理方向

- 共享类型只保留一份事实来源，renderer 的全局声明与共享接口分离维护。
- 文档采用稳定主题名，不再用“建议 / 演示 / 分析 / 设想”作为正式文档结构。
- `.gitignore` 与 `.gitattributes` 以当前真实产物和 LFS 资产为准持续收敛。
- 测试与回归以 `typecheck`、`build` 和关键 E2E 主链为最低要求。

## 变更原则

- 不为了整理而重写业务行为。
- 结构治理优先服务于功能保真、UI/UX 保真和后续维护成本降低。
