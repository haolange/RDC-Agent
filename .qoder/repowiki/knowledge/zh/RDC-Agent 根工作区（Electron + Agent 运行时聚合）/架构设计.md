根工程是 RDC-Agent 的单一发布单元：`package.json` 通过 `electron-vite`（`electron.vite.config.ts`）将 `src/main`、`src/preload`、`src/renderer` 分别编译为 Electron 主进程、预加载脚本与 React 渲染进程，共享 `@shared` 别名；`vite.renderer.config.ts` 单独暴露 Vite dev server，`vitest.config.ts` 统一运行全仓单测。运行时静态资源（Agent/Skill/Hook/Prompt/图标）集中在 `resources/`，由主进程在启动时按 builtin/user/project 优先级加载；`scripts/` 提供架构门禁、保真度校验、覆盖率 ratchet、会话隔离与发布制品校验等 Node 工具，全部通过 `pnpm run check:*` 暴露为顶层命令；`tests_and_coverage/` 提供纯 HTML/JS 的 Work Process CoT 演示，用于浏览器 QA 场景验证。`DESIGN.md` 作为裁决文档集中定义产品边界、架构不变量与迁移目标，所有子模块的实现与门禁均受其约束。
