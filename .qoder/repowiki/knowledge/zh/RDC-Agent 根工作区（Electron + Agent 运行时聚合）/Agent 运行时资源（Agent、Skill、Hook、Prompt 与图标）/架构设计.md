资源按职责分目录组织，全部由 agent-runtime 在启动时按需装载：
- `agents/*.agent.md`：以 YAML front matter + Markdown body 描述 Agent 元数据（name、tools、skills、handoffs、mcp-servers、model 等），其中 `general.agent.md` 作为默认入口并声明对 debugger/analyzer/optimizer 的 handoff。
- `prompts/*.md`：纯文本系统提示词（如 `agent-loop.md`、`completion.md`、`identity-collaboration.md`、`tool-evidence.md`），被 Agent 循环与 Skill 组合引用。
- `skills/<name>/SKILL.md`：每个 Skill 一个目录，通过 YAML front matter 声明 name/description，正文以中文编写具体方法与协作协议（如 `execution-orchestrator` 规定 Task/Capsule/子执行契约）。
- `hooks/*.hook.yml` + `*.mjs`：YAML 声明钩子触发事件（如 `tool.before-call`）、匹配工具、超时与失败策略；对应的 `.mjs` 脚本通过 `hook-check-lib.mjs` 暴露的 `readHookContext`/`pass`/`fail` 读取上下文并校验产物完整性（如 `artifact-integrity` 校验 `sourceRefs` 与 `contentHash` 的 sha256 格式）。
- `icons/`：桌面应用多格式图标（.icns/.ico/.png）。
- `knowledge/seed/{library,spec}/README.md`：种子知识库占位说明。
依赖方向单向：Agent/Skill/Prompt/Hook 均为只读配置，由上层 agent-runtime 解析后注入到执行引擎，模块内部无相互代码依赖。
