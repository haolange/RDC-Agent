- Agent、Skill 与 Prompt 统一采用 YAML front matter 声明元数据（name/description/target/model 等），正文用 Markdown 编写行为说明。
- 每个 Skill 独立放在 `skills/<skill-name>/SKILL.md` 目录下，便于按名称发现与按需加载。
- Hook 以 `<name>.hook.yml` + `<name>.mjs` 成对组织，YAML 仅声明触发条件与参数，实际校验逻辑写在同名 JS 中并通过共享库 `hook-check-lib.mjs` 访问上下文。
- Hook 脚本通过 `pass('...')` / `fail('...')` 表达校验结果，并使用 `timeoutMs` 限制执行时长，`failurePolicy: block` 用于阻断不合规调用。
- Agent 通过 `handoffs` 字段声明向 debugger/analyzer/optimizer 等专用 Agent 的交接标签与 prompt，并由 `general.agent.md` 作为默认入口聚合所有子 Agent。
