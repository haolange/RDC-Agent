根目录统一入口：`pnpm dev` / `pnpm start` 经 `scripts/launch-rdc-agent.mjs` 按 `--mode desktop|desktop-dev|browser|browser-dev|prepare-only` 启动不同运行面；`pnpm build` 调用 `electron-vite build`，`pnpm dist` / `pnpm pack` 走 electron-builder；`pnpm run check:gates` 串联仓库卫生、类型检查、lint、测试、覆盖率 ratchet、架构门禁、设计 token 门禁、渲染结构门禁、Browser capability 门禁、发布配置门禁等全套门禁；`pnpm test:coverage` 生成覆盖率并由 `check:coverage-ratchet` 保证只升不降。
