- 所有跨主进程/预加载/渲染进程的契约与类型集中在 `src/shared`，并通过 `@shared` alias 在三端统一引用。
- 新增或修改能力必须配套 `pnpm run check:<feature>` 脚本，门禁失败即视为未完成，不得仅凭 commit message 宣称实现。
- Renderer 组件禁止直接调用 `window.electronAPI`，IPC 调用必须经 `src/shared/renderer-api` 工厂并按 channelCapabilities 分类声明。
- CSS 仅允许语义 design-token 与刻度变量，禁止 primitive 颜色、hex、px 字号间距与 `!important`，由 `check:design-tokens` 强制。
- Provider 模型清单以 manifests JSON 为基线真值，TS 层只做 Schema/Compiler/Registry/Resolver/Planner/Adapter，用户覆盖不得触碰安全字段。
- 存储写入采用 atomic rename + lock 文件，未知更高 schemaVersion 一律 fail-closed，禁止静默兼容双轨。
