- 跨进程共享代码统一放在 src/shared，并通过 @shared 别名在 main、preload、renderer 三方引用
- 所有跨子系统约束（架构、fidelity、设计令牌、工作流呈现等）以 scripts/*.mjs 形式实现并由 package.json 中 check:* 脚本统一触发
- 资源文件采用 YAML front matter + Markdown 声明式描述，由 resources 目录集中托管并被主进程按需加载
- 测试按 src/**/*.test.ts 命名约定组织，vitest 仅对 src/main 与 src/shared 计算覆盖率，渲染器行为通过浏览器 QA 与 check:* 脚本验证
