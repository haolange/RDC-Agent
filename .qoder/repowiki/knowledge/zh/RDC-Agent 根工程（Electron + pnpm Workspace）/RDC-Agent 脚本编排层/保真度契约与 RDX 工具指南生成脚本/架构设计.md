本模块由三个独立的 Node.js ESM 脚本组成，均通过 `node scripts/xxx.mjs` 直接执行，无运行时依赖：
- `extract-fidelity-contract.mjs`：递归遍历 `src/renderer` 下所有 `.tsx`，用正则匹配 `className`、`data-testid`、`dataTestId` 以及 `cn()` 字面量，将结果去重排序后写入 `scripts/fidelity/fidelity-classnames.txt` 与 `fidelity-testids.txt`；对 `ResizeHandle.tsx` 做特殊硬编码以覆盖其有限 side union 生成的类名。
- `extract-shared-exports.mjs`：递归扫描 `src/shared` 下所有 `.ts/.tsx`（排除 `.d.ts`），按行解析 `export { ... }`、`export type *`、`export default` 等语法，输出到 `scripts/fidelity/shared-exports.txt`。
- `generate-rdc-tool-guides.mjs`：读取外部 `tool_catalog.json`（默认位于仓库外的 `RDC-Agent-Tools/spec/tool_catalog.json`）与本地 `resources/agent-runtime/rdc-tool-guide-members.json`，对每个 profile 的 operations 列表进行存在性、重复性与 scope/effect 白名单校验，使用内置 JSON Schema 验证器生成示例参数，渲染 Markdown 到 `resources/agent-runtime/skills/<skillId>/references/tools.md`；支持 `--check` 模式用于 CI 校验文件是否陈旧。
三个脚本之间无相互引用，各自独立消费文件系统并以 stdout 日志报告产出路径与条目数。
