本模块为纯数据与脚本资源目录，无代码依赖，由上层 agent-runtime 在启动时按目录发现并装载：
- `agents/*.agent.md`：每个 Agent 一个文件，YAML front matter 声明 name/description/target/model/tools/skills/handoffs/mcp-servers 等元数据；`general.agent.md` 作为默认入口，通过 agents 字段聚合 debugger/analyzer/optimizer 三个专用 Agent。
- `prompts/*.md`：纯文本系统提示词（agent-loop、completion、identity-collaboration、tool-evidence），被 Agent 循环与 Skill 组合引用。
- `skills/<name>/SKILL.md`：每个 Skill 独立目录，front matter 声明 name/description，正文用中文描述方法与协作协议（如 execution-orchestrator 规定 Task/Capsule/子执行契约）。
- `hooks/*.hook.yml` + `<name>.mjs`：YAML 仅声明 id/event/command/args/timeoutMs/failurePolicy/matcher；同名 `.mjs` 通过共享库 `hook-check-lib.mjs` 暴露的 `readHookContext`/`pass`/`fail`/`isSha256Prefixed` 读取 HookEngine 注入的 stdin JSON 上下文并校验产物完整性（如 artifact-integrity 校验 sourceRefs 与 contentHash 的 sha256 格式）。
- `icons/`：桌面应用多格式图标（.icns/.ico/.png）。
- `knowledge/seed/{library,spec}/README.md`：种子知识库占位说明。
依赖方向单向：所有资源均为只读配置，由 agent-runtime 解析后注入执行引擎。
