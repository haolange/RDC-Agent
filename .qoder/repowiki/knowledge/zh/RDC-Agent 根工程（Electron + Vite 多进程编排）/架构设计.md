根工程作为唯一入口，通过 tsconfig.json 中的 @main/@renderer/@shared 路径别名将 src/main（Electron 主进程）、src/preload（桥接）与 src/renderer（React 渲染器）纳入同一类型系统；electron.vite.config.ts 驱动 electron-vite build 产出 out/ 目录，vite.renderer.config.ts 提供浏览器侧独立开发服务，scripts/launch-rdc-agent.mjs 根据 --mode 参数在 desktop / browser / prepare-only 等启动模式间切换。src/shared 是跨子模块的唯一代码共享边界，所有跨子系统约束由 scripts/*.mjs 实现并通过 package.json 中大量 check:* 命令串联执行，最终由 check:gates 统一触发。resources/* 以 YAML front matter + Markdown 声明 Agent/Skill/Prompt/Hook 等运行时资源，被主进程按需加载；tests_and_coverage 中的纯 HTML/JS 验收套件与 vitest 配置共同覆盖 Node 侧 unit test 与浏览器侧场景回放两条验证路径；electron-builder.json 将 out/** 与 resources/* 打包为 Windows NSIS 安装器。pnpm-workspace.yaml 集中管理 storeDir、overrides（如 yauzl 3.3.1 修复 electron@42 在 Node ≥24.16 下的挂起问题）与 allowBuilds。
