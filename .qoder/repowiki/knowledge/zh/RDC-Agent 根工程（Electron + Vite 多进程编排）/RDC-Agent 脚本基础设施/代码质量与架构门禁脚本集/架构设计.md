本模块由两类脚本组成：
- 独立检查脚本（`scripts/check-*.mjs`）：每个文件对应一个单一门禁职责，如 `check-architecture.mjs` 校验 src 目录分层与行预算、`check-repository-hygiene.mjs` 校验 git 跟踪/根文件/锁文件/launcher 路由、`check-git-diff.mjs` 基于环境变量解析 base ref 并调用 `git diff --check`、`check-coverage-ratchet.mjs` 对比 vitest 覆盖率与 `scripts/fidelity/coverage-ratchet.json`。
- 共享基础设施 `system-debt-ratchet.mjs`：被多个 check 脚本通过 `import` 引用，提供规则注册表评估（`evaluateRegistry`）、多种 probe 类型（`file-exists` / `dir-exists` / `walk-pattern` / `walk-path-and-content` / `profile-knowledge-ceiling` / `contract-suite`）、债务 JSON 文档的 schema 校验与历史单调性比较、以及通过子进程调用 vitest 执行契约测试套件。
依赖方向单向：具体 check 脚本 → `system-debt-ratchet.mjs` → node 内置 fs/path/child_process；所有脚本以 CLI 形式直接运行（`#!/usr/bin/env node`），通过 `process.exitCode` 或 `process.exit()` 上报失败，并通过 `isDirectInvocation(import.meta.url)` 区分被 require/import 与直接调用的场景。
