本模块为纯文档与静态资源目录，按职责划分为五个子目录：`contracts/` 定义跨层稳定契约（runtime kernel、permissions、failure model、session projection），作为权威规范；`architecture/` 描述模块地图、数据流、实现向架构说明，并统一指向 `contracts/` 避免双轨权威；`product/` 记录产品定位、scoped runtime resources、垂直能力与验收账本；`ui/` 覆盖 Workbench、Design System 与 Knowledge Center；`workflows/` 描述 Debugger 主链流程。根级 `docs/README.md` 规定推荐阅读顺序（仓库根 README → DESIGN.md → AGENTS.md → contracts → architecture overview/module-map），引导读者从顶层契约逐步深入。`designs/rdc-agent-design-system/` 提供只读 HTML 预览，直接引用运行时 `src/renderer/styles/design-system.css` 与 `src/renderer/ui/kit.css`，禁止复制 token，确保视觉与运行时一致。
