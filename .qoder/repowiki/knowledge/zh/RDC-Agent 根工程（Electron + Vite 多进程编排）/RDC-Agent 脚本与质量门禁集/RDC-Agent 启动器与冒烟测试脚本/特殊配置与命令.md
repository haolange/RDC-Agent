`smoke-desktop-health.mjs` 需先执行 `pnpm run pack` 生成 `release/{linux-unpacked,win-unpack,mac*}` 目录；`smoke-agent-browser-qa.mjs` 可通过 `RDC_AGENT_SMOKE_START=1` 自动拉起 `start:agent-browser`，或通过 `RDC_AGENT_SMOKE_BRIDGE_URL`/`RDC_AGENT_SMOKE_QA_URL` 指向已有实例；`RDC_AGENT_SMOKE_TIMEOUT_MS`、`RDC_AGENT_SMOKE_DESKTOP_MS` 控制超时；`RDC_AGENT_NODE` 可指定 Node 二进制路径。
