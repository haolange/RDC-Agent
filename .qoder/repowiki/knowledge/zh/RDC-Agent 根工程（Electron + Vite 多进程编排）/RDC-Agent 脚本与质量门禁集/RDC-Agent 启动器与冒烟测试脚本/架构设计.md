本模块由两类独立脚本组成：
- 启动器入口层：`run-rdc-launcher.{sh,cmd}` 负责解析 `RDC_AGENT_NODE`、回退到系统或 Codex 内置 Node.js（≥22.13.0），再 `exec` 调用 `scripts/launch-rdc-agent.mjs`；`start-rdc-agent.{sh,cmd}` 仅作为薄包装把 `--mode desktop` 透传给 launcher，屏蔽平台差异。
- 冒烟测试层：`smoke-desktop-health.mjs` 通过 `child_process.spawn` 启动已 `pnpm pack` 产出的 Electron 可执行文件（自动探测 linux/win/mac 目录结构），在超时后终止并断言进程正常退出；`smoke-agent-browser-qa.mjs` 可选地用 `pnpm run start:agent-browser` 拉起 Browser Bridge，从子进程日志中解析一次性 `/qa?qaBootstrap=...` URL，随后对 `/qa`、`/app`、`/invoke`、`/events` 等端点发起 HTTP 请求，验证 302+Set-Cookie、401 JSON、CORS Origin 校验及 `app:getMeta` 调用成功；`open-agent-browser-qa.html` 是供人工打开的说明页。
依赖方向单向：启动器 → `launch-rdc-agent.mjs`；冒烟测试 → 被测服务（HTTP）或被测 Electron 进程（spawn），不反向依赖业务代码。所有脚本以 ESM `.mjs` 形式运行于 Node，并通过环境变量（如 `RDC_AGENT_SMOKE_*`、`RDC_AGENT_USER_DATA`、`RDC_AGENT_NODE`）进行配置。
