该模块按职责将脚本划分为四个并列子域：quality_checks 提供架构/覆盖率/Git 卫生等门禁；fidelity_and_extraction 通过扫描渲染层 TSX 生成 className/data-testid/shared exports 契约并产出 RDX tools.md；launchers_and_smoke_tests 封装 Electron/Browser 两种模式的 RDC-Agent 启动与冒烟验证；runtime_helpers 提供构建期工具（pnpm 解析、Provider 索引、TS 源码直载）与 Vitest 隔离环境初始化。各子域脚本均基于 Node ESM，通过 scripts/ 根目录下的入口文件被统一调用，并以 fidelity/ 基线 JSON 与 release/ 配置作为跨子域共享的数据契约，使质量检查与契约提取在 CI 中形成闭环。
