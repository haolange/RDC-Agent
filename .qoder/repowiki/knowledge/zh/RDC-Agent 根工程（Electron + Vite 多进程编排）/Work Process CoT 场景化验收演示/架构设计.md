模块以 `index.html` 为入口，加载 `shared/` 下的共享脚本：`i18n.js`（多语言）、`render.js`（CotRender.mount 将模型渲染到 DOM）、`mock-runtime.js`（提供 `createPlayer` 按阶段推进并定时刷新 UI）、`shell.js`（挂载外壳与主题切换）、`icons.js`、`tokens.css`、`work-process.css`。`scenarios/` 目录存放 12 个独立 HTML 场景文件，每个对应一种 CoT 用例（happy path、running/streaming、completed/stopped、tool families、aggregate、compact、plan/tasks、approval、opaque answer、error recovery、markdown surfaces）。`shared/scenario-page.js` 作为通用场景启动器，根据 `data.scenario` 从 `scenarios-data.js` 取模型并通过 `CotRender.mount` 挂载到 `#wp-mount` / `#final-mount` / `#alt-wp-mount`。`scenarios-data.js` 集中定义所有场景的 JSON 模型（含 thinking、prose、items、extras、final 等字段），由 `buildDemoModel` 在 mock 运行时中按 phase 增量构建，形成“数据驱动 + 伪播放器”的两层结构；依赖方向单向：HTML → shared 脚本 → scenarios-data/mock-runtime → CotRender/CotShell，不反向依赖被测源码。
