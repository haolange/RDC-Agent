- 脚本统一以 `process.cwd()` 推导仓库根，再拼接相对路径访问 `src/*` 与 `resources/*`，使脚本可在任意工作目录下运行。
- 输出前对集合去重并按 `localeCompare` 排序，保证多次运行产生稳定、可 diff 的文本产物。
- 通过 `fs.mkdirSync(outDir, { recursive: true })` 确保输出目录存在后再写入文件。
- 对外部 JSON 输入在读取后立即进行结构性断言（如 catalog 长度一致性、操作名唯一性、scope/effect 白名单），失败时抛出带 `[module:tag]` 前缀的错误信息。
- 对可能缺失的外部资源（如 catalog 文件）采用显式 `fail` 函数集中报错，而非静默降级。
