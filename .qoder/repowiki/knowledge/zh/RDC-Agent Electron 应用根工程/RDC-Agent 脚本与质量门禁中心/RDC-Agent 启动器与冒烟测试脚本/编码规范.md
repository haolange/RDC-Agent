- 每个脚本定义统一的 `fail(message)` 与 `ok(message)` 辅助函数，前者设置 `process.exitCode = 1` 并输出带前缀的错误日志，后者输出带前缀的成功日志。
- 通过 `process.env.RDC_AGENT_*` 命名空间的环境变量注入配置（如 `RDC_AGENT_SMOKE_*`、`RDC_AGENT_USER_DATA`、`RDC_AGENT_NODE`），避免硬编码路径或端口。
- 子进程终止采用跨平台策略：Windows 调用 `taskkill /pid <pid> /t /f`，Unix 先 `SIGTERM` 等待最多数秒后再 `SIGKILL`，确保进程树被清理。
- 启动器脚本以 `#!/usr/bin/env sh` / `@echo off` 开头，使用 `set -eu` 或 `setlocal` 保证错误快速失败，并通过 `exec` 或 `call` 将控制权交给真正的 launcher。
- 冒烟测试通过 `fetch` 检查 HTTP 状态码与 `Content-Type`（如 302 + Set-Cookie、401 JSON、HTML 响应）来断言服务端行为，而非依赖浏览器自动化。
