该模块由一组相互独立、职责单一的 Node.js 脚本组成，按用途分为四类：
- 契约校验类：`builtin-profile-contracts.mjs` 通过 `register-ts-source.cjs` 动态加载 `src/main/settings/agentManifestParse.ts` 与 `src/shared/constants/agentToolTokens.ts`，对 `resources/agent-runtime/agents/*.agent.md` 和 `skills/*/SKILL.md` 执行严格的前置字段、工具白名单/黑名单、handoff 结构校验；`renderer-contract.mjs` 从 `scripts/fidelity/renderer-contract.json` 加载受控文件清单，提供 `scriptRead`/`scriptExists`/`contractGroup` 等白名单访问入口，并支持 CSS `@import` 递归内联与债务基线 ratchet。
- 依赖解析类：`pnpm-resolver.mjs` 按优先级枚举本地 `node_modules`、corepack、系统 PATH、缓存目录中的 pnpm 可执行文件，匹配固定版本 `11.7.0`，失败时输出诊断信息。
- 模块桥接类：`provider-catalog-index.cjs` 作为 CommonJS 入口调用共享编译器生成 provider 目录索引；`register-ts-source.cjs` 通过 patch `Module._resolveFilename` 与注册 `.ts/.tsx` 扩展，使 Node 可直接 require TypeScript 源码并支持 `@shared/` 别名与虚拟模块 `virtual:rdc-provider-catalog-index`。
- 测试环境类：`vitest-global-setup.ts` 在 Vitest 启动前创建临时根目录并注入 `RDC_AGENT_HOME`/`RDC_AGENT_USER_DATA`/`RDC_AGENT_QA_INSTANCE_ID` 环境变量，确保每个 worker 拥有隔离的 ~/.rdx 且进程结束后自动清理。
依赖方向单向指向 `src/` 下的真实实现，本模块自身不引入业务逻辑，仅承担构建期与运行期基础设施职责。
