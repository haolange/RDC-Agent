- 每个场景以 `NN-kebab-case.html` 编号命名于 `scenarios/` 下，并在文件名中体现该场景要验证的行为特征。
- 场景数据统一通过 `scenarios-data.js` 中的 `models()` 返回对象描述，包含 `note`、`user`、`wp`、`final`、`altNote`、`altWp` 等字段，供 `scenario-page.js` 消费。
- 运行态模型遵循固定 schema：顶层 `status`/`duration`/`actionCount`，`sections[].thinking.kind` 区分 raw/summary/opaque，`prose.streaming` 控制流式闪烁，`items[].type` 区分 tool/aggregate/summary/taskSnapshot/ask_user/approval。
- 多语言文案通过 `CotI18n.getLocale() === 'en'` 三元判断在场景数据内选择中英文，而非拆分文件。
- UI 交互通过 `data-*` 属性（如 `data-play`、`data-replay`、`data-jump`、`data-note`、`data-user`）配合事件监听实现，避免直接操作 ID。
- 共享逻辑封装为 IIFE 并挂到 `window` 上的全局命名空间（`Cot*`），各脚本按依赖顺序 `<script>` 引入，不使用 ES module。
