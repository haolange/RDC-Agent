scripts/ 作为顶层编排层，将四类职责并列组织：quality_checks（check-*.mjs）在 CI 中执行架构分层、覆盖率基线、系统债务上限与 Git 卫生等门禁；fidelity_and_extraction 扫描渲染层 TSX 提取 className/data-testid/shared exports 契约，并基于 tool_catalog.json 生成各 RDX 专业的 tools.md 参考文档；launchers_and_smoke_tests 封装 Electron/Browser 两种模式的 RDC-Agent 启动入口与冒烟验证；runtime_helpers 提供构建期工具（pnpm 解析、Provider 目录索引、TS 源码直载）与 Vitest 隔离环境初始化；release/*.mjs 负责发布前的 checksum 与 SBOM 生成。各子域共享 scripts/fidelity/ 下的 JSON/TXT 基线文件作为契约数据源，使质量检查与契约提取在 CI 中形成闭环。
