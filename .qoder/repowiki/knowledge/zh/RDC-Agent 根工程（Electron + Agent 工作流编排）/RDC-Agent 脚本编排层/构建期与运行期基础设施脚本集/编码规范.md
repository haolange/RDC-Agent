- 所有契约校验函数统一采用局部 `assert(condition, message)` 形式抛出错误，并在消息中包含被校验实体的标识符以便定位问题。
- 路径处理统一通过 `path.join` + `normalize`（将反斜杠替换为正斜杠）来保证跨平台一致性，并在读取文件前先做 `fs.existsSync` 检查再抛错。
- 对外暴露的 API 以纯函数形式导出（如 `extractFrontmatterScalar`、`assertParsedProfileContracts`、`scriptRead`、`resolvePnpm`），避免在模块顶层持有可变状态。
- 配置文件（如 `renderer-contract.json`、pnpm 版本常量）集中声明并通过只读变量导出，禁止在业务逻辑中硬编码字符串字面量。
- 测试环境通过全局 setup 函数设置隔离环境变量并在返回的清理函数中删除临时目录，确保多 worker 互不干扰。
