模块以 `index.html` 作为主入口，加载 `shared/` 下的共享脚本：`i18n.js`（多语言）、`render.js`（暴露 `CotRender.mount` 将模型渲染到 DOM）、`mock-runtime.js`（提供 `createPlayer` 按 phase 增量推进并定时刷新 UI）、`shell.js`（挂载外壳与主题切换）、`icons.js`、`tokens.css`、`work-process.css`。`scenarios/` 目录存放 12 个独立 HTML 场景文件，每个对应一种 CoT 用例；每个场景页面通过 `<body data-scenario="NN">` 标识自身编号，由 `shared/scenario-page.js` 在 DOMContentLoaded 时读取该 id，从 `scenarios-data.js` 的 `models()` 取模型并通过 `CotRender.mount` 挂载到 `#wp-mount` / `#final-mount` / `#alt-wp-mount`。`mock-runtime.js` 中的 `buildDemoModel(phase)` 按阶段递增构建运行态模型（thinking → prose → tool items → planReview/taskSnapshot → final），配合 `intervalMs` 定时器驱动播放、暂停、重放、跳转完成等交互。依赖方向单向：HTML → shared 脚本 → scenarios-data/mock-runtime → CotRender/CotShell，不反向依赖被测源码。
